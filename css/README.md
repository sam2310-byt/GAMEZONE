# GameZone E-Commerce Website

## About the Project

GameZone is a responsive front-end e-commerce website designed for gamers. The website allows users to browse gaming products, view product information and manage products in a shopping cart.

The project was created using HTML, CSS and JavaScript.

## Features

- Responsive website design
- Home page
- Product listing with 12 products
- Product detail view
- Product search
- Add products to shopping cart
- Remove products from shopping cart
- Increase and decrease product quantities
- Automatic cart total calculation
- About page
- Contact page
- Contact form validation
- Accessibility improvements

## Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- Local Storage

## How to Run the Website

1. Open the GameZone project folder in Visual Studio Code.
2. Open `index.html`.
3. Run the website using Live Server.
4. Use the navigation menu to browse the website.

No backend or additional libraries are required.

## Accessibility

The website was tested using Google Chrome Lighthouse. Accessibility improvements were made based on the Lighthouse audit results.
