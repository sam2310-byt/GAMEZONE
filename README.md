# GameZone E-Commerce Website

## About the Project

GameZone is a responsive front-end e-commerce website designed for gamers. Users can browse gaming products, view product details and manage products in a shopping cart.

The project was created using HTML, CSS and JavaScript.

## Features

- Responsive website design
- 12 gaming products
- Product detail view
- Product search
- Add products to cart
- Remove products from cart
- Increase and decrease quantities
- Automatic cart total
- About page
- Contact page
- Contact form validation
- Accessibility testing

## Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- Local Storage

## How to Run

1. Download or clone the project.
2. Open the project folder in Visual Studio Code.
3. Open `index.html`.
4. Run the website using Live Server.

No backend or external libraries are required.

## Accessibility

The website was tested using Google Chrome Lighthouse and accessibility improvements were made based on the audit results.
